# Asset provenance

ValoPeek branding, social artwork and the Ascent sample export were copied from the existing product assets. The export uses three anonymized sample Competitive matches and must remain labelled as an example.

Map thumbnails came from the product's existing map artwork. These are not labelled callout diagrams. VALORANT and associated artwork belong to Riot Games; the product includes the independent-product notice.

Current-interface screenshots use sanitized sample match data. See [screenshot provenance](screenshots/README.md) for capture dimensions, fixture limitations and source revision.

No blanket open-source license is applied to Riot artwork or these assets.

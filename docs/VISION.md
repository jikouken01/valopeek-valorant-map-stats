# The ValoPeek product vision

[Product overview](../README.md) · [Try ValoPeek](https://valopeek.app/)

ValoPeek aims to make personal VALORANT match review easier to understand. A scoreboard gives a result. A map connects it to the fights and areas behind it.

## Available today

The current browser tool analyzes available Competitive history from the current act. It includes personal map zones and K/D, recorded positions, duel lines when both endpoints exist, selection and context filters, available round timelines, personal agent stats and shareable zone images. Labelled map callouts are also available.

Requested imports persist across page closures and API restarts. Provider coverage and event details can still be incomplete.

## What guides our decisions

- **Explain the numbers.** Say what a metric measures and which selection it represents.
- **Show context.** Connect a map result to the fights and available round details.
- **Respect missing data.** Unavailable isn't zero, and coverage limits should stay visible.
- **Keep review personal.** Avoid implying global meta statistics or skill judgments from selected matches.
- **Help discussion.** Make it easier to share an example and ask a specific question.

## Where we want to go

Our direction is clearer map context, understandable statistics and useful ways to discuss recorded fights. These are goals, not release commitments or features already shipped.

Useful feedback describes your task: the question you wanted to answer, the context you needed, and what made the review difficult.
